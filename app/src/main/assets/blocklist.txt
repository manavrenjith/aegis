# Aegis bundled malicious-domain blocklist (sample data for the hackathon build)
#
# Format: one domain per line. Lines beginning with '#' and blank lines are ignored.
# Matching is EXACT domain only, case-insensitive (a trailing dot is stripped).
#   e.g. "sbi-onlin-login.com" matches sbi-onlin-login.com but NOT www.sbi-onlin-login.com
# On first app run these are loaded into the SQLite 'blocklist' table, then held
# in memory and checked on every DNS lookup / TLS SNI. Matches are auto-blocked
# (DNS response is sinkholed to NXDOMAIN) and logged with threat_type
# "known phishing domain".
#
