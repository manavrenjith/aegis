# AEGIS
Non-root Android Firewall
AEGIS is a lightweight, privacy-focused Android firewall built on the Android VpnService API. It gives you full visibility and control over every app's network access — no root required.

## Features

Per-app firewall rules — block or allow network access for any installed app
Live activity log — see every packet in and out, with domain, app, direction, and timestamp
Network usage tracking — monitor data consumption per app
App-level detail view — tap any app to inspect its full connection history and configure its rules
Simple settings — configure DNS, logging behavior, and default block policy
Material 3 dark UI — clean, minimal interface built for daily use

## About

AEGIS started as an educational project to demonstrate Android VPN service development, network packet filtering, and native JNI integration. It showcases best practices for building system-level Android applications with real-time network monitoring capabilities.
